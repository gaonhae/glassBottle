#  PRD: 가족 소통 개선 웹서비스 (MVP)

---

## 1. 제품 개요

### 1.1 제품명 (가칭)

* 유리병 (GlassBottle)

### 1.2 제품 정의

가족 간의 정서적 연결을 강화하기 위해
비동기적이고 부담 없는 방식으로 대화를 유도하는 웹 기반 서비스

---

## 2. 문제 정의 (Problem Statement)

### 2.1 핵심 문제

* 물리적 거리 → 정서적 거리로 이어짐
* 가족 간 대화 주제가 점점 단순/피상적으로 변함
* “연락해야지” → 실행되지 않음

### 2.2 문제 구조

| 문제          | 원인         | 결과       |
| ----------- | ---------- | -------- |
| 대화 빈도 감소    | 바쁨, 심리적 거리 | 관계 약화    |
| 깊이 있는 대화 부족 | 공통 주제 부재   | 감정 공유 단절 |
| 연락의 부담      | 타이밍/형식 부담  | 지속성 저하   |

---

## 3. 목표 (Goals)

### 3.1 제품 목표

* 가족 간 정기적 상호작용 유도
* 깊이 있는 대화 발생 증가
* 심리적 부담 최소화

### 3.2 KPI

| 지표     | 목표              |
| ------ | --------------- |
| WAU    | 가족 그룹 기준 70% 이상 |
| 질문 응답률 | 60% 이상          |
| 편지 열람률 | 80% 이상          |
| 4주 유지율 | 40% 이상          |

---

## 4. 타겟 사용자

### Primary

* 20대 독립 거주 청년

### Secondary

* 40~50대 부모

---

## 5. 핵심 가치 제안

> 부담 없이, 자연스럽게, 가족과 더 깊이 연결된다

---

## 6. 핵심 기능

---

## 6.1 질문 기반 소통 (Conversation Prompts)

### 기능 설명

* 가족 그룹 전체에 동일한 질문 제공
* 구성원 각각 답변 작성
* 답변은 한 페이지에서 카드 형태로 일괄 조회
* 카드 클릭 시 답변 상세 및 댓글 UI 진입

---

### 6.1.1 세부 요구사항

| 항목    | 요구사항         |
| ----- | ------------ |
| 질문 제공 | 하루 1회 (기본)   |
| 답변 작성 | 텍스트          |
| 답변 조회 | 카드 리스트 형태    |
| 카드 정보 | 작성자, 내용, 시간  |
| 상세 화면 | 답변 + 댓글      |
| 댓글    | 가족 구성원 작성 가능 |

---

### 6.1.2 UX 목표

* 가족 답변을 한 번에 쉽게 소비 가능
* 특정 답변에 대해 자연스럽게 반응 가능
* 최소 클릭으로 interaction 가능

---

## 6.2 유리병 편지 (Delayed Message)

### 기능 설명

* 편지를 작성 후 랜덤 시간 뒤 전달

### 요구사항

| 항목    | 요구사항            |
| ----- | --------------- |
| 전달 시간 | 랜덤 (1~72시간)     |
| 상태    | 작성됨 / 이동 중 / 도착 |
| 알림    | 도착 시 알림         |

## 8. UX/UI 요구사항

### 8.1 플랫폼 범위

* MVP 단계에서는 **모바일 전용 UI**로 설계한다.
* 지원 디바이스는 스마트폰 브라우저를 기준으로 한다.
* PC 및 태블릿은 정식 지원 대상에서 제외한다.
* PC 또는 태블릿으로 접속한 경우, 서비스 기능을 노출하지 않고 **“모바일로 접속해 달라”는 안내 화면만 표시**한다.

### 8.2 설계 원칙

* 모든 주요 화면은 모바일 세로 화면을 기준으로 설계한다.
* 한 손 조작이 가능하도록 주요 액션 버튼은 하단 또는 손이 닿기 쉬운 영역에 배치한다.
* 부모 세대를 고려해 큰 터치 영역, 큰 글자, 낮은 정보 밀도를 유지한다.
* 입력 단계 수를 최소화하여 서비스 이용 피로를 줄인다.

### 8.3 질문 목록 화면

| 항목   | 요구사항          |
| ---- | ------------- |
| 레이아웃 | 모바일 기준 카드 리스트 |
| 가독성  | 큰 글씨, 단순 구조   |
| 클릭   | 카드 전체 클릭 가능   |
| 스크롤  | 세로 스크롤 중심     |

### 8.4 답변 상세 화면

| 항목  | 요구사항             |
| --- | ---------------- |
| 상단  | 질문 표시            |
| 본문  | 답변 내용            |
| 하단  | 댓글 목록 + 입력       |
| 조작성 | 모바일 한 손 조작 가능 수준 |

### 8.5 비지원 디바이스 처리

| 디바이스 | 처리 방식           |
| ---- | --------------- |
| PC   | 모바일 접속 안내 화면 표시 |
| 태블릿  | 모바일 접속 안내 화면 표시 |

## 9. 기술 요구사항

| 영역       | 기술          |
| -------- | ----------- |
| Frontend | Next.js     |
| Backend  | Next.js API |
| DB       | MySQL       |
| ORM      | Prisma      |
| Infra    | AWS         |

### 9.1 클라이언트 정책

* 모바일 브라우저를 1차 지원 대상으로 한다.
* User-Agent 및 viewport 기준으로 PC/태블릿 접속을 감지한다.
* 비지원 디바이스에서는 기능 화면 대신 안내 화면만 렌더링한다.
